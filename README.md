# e-plantShopping

## Paradise Nursery – Online Plant Shop

**e-plantShopping** is a React-based online plant shopping application developed for the Paradise Nursery project. Users can browse plants, view plant details, add plants to a shopping cart, update quantities, remove items, and view the total price.

## Features

* Browse a variety of plants
* View plant names, descriptions, prices, and images
* Add plants to the shopping cart
* Increase or decrease plant quantities
* Remove plants from the cart
* Automatically calculate cart totals
* Dynamic shopping cart updates
* User-friendly interface
* Responsive design

## Technologies Used

* React
* JavaScript
* HTML
* CSS
* Redux Toolkit
* Git
* GitHub

## Objective

The objective of e-plantShopping is to provide a functional and interactive online plant-shopping experience while demonstrating React components, state management, Redux functionality, dynamic rendering, and shopping cart operations.
